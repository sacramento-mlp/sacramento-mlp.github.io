# Mário Sacramento — Website Profissional

Portfólio pessoal de Mário Sacramento, alojado em GitHub Pages.

## Tecnologias
Astro 5, TypeScript, CSS responsivo, GitHub Actions.

## Desenvolvimento local
Requer Node.js 22 ou superior.

```bash
npm install
npm run check
npm run build
npm run dev
```

## Publicação
1. Abrir **Settings → Pages** neste repositório.
2. Em **Build and deployment → Source**, selecionar **GitHub Actions**.
3. Abrir **Actions**, executar o workflow **Deploy GitHub Pages** se necessário.
4. Consultar https://sacramento-mlp.github.io após a publicação.

## Notas
- O website é um portfólio e montra informativa; não processa pagamentos.
- Os produtos estão em desenvolvimento, sem vendas ativas.
- Não colocar código privado, segredos ou chaves de licença neste repositório.
- O currículo e a biografia detalhada aguardam validação do autor.
